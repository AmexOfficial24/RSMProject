# RSM Data Analysis Tool

A Python-based data analysis application with a GUI. This was originally developed as a college project for **RSM**, It is designed to validate data, generate graphs, and provide text-based reports.

**You are free to use, edit, or repurpose this code for your own projects.**

## Features

* **GUI:** User-friendly interface built with Tkinter (includes Dark Mode).
* **Visuals:** Generates bar graph analyses for quick metric comparison.
* **Reporting:** outputs detailed text reports with clear interpretations of the data.
* **Safety:** Includes data validation to prevent errors during processing.
